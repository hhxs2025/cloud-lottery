# 🎉 云抽奖

一款专为飞牛 fnOS 设计的年会/活动抽奖应用，支持多奖项、名单导入、内定人员、实时滚动抽奖。


## ✨ 功能

- **多奖项管理** – 支持设置多个奖项（特等奖、一二三等奖等），每个奖项独立配置名额和奖品
- **名单导入** – 支持 `.txt` 或 `.xlsx` 格式导入候选人名单
- **候选人头像** – 为每位候选人上传照片，抽奖时滚动展示
- **实时抽奖** – 点击抽奖，姓名滚动动画自动揭晓中奖者
- **内定功能** – 支持为奖项预设内定人员，抽奖时优先内定
- **中奖记录** – 自动记录所有中奖信息，支持一键清空重置
- **页面定制** – 后台可编辑前台顶部内容（支持图片、轮播图、自定义样式）
- **前台样式** – 可自定义活动名称、标题颜色、背景颜色、标题字号


## 📦 安装

1. 下载 `cloud-lottery.fpk` 安装包
2. 登录飞牛 fnOS → 应用中心
3. 点击「手动安装」→ 选择 `.fpk` 文件 → 确认安装


## 🚀 快速上手

### 1. 打开应用
安装完成后，点击应用卡片「打开」，进入前台抽奖页面。

### 2. 登录后台
点击右上角「⚙️ 后台管理」，使用默认账号登录：

| 字段 | 默认值 |
|------|--------|
| 用户名 | `admin` |
| 密码 | `ynos1234` |

### 3. 配置活动
按顺序操作：

1. **活动设置** – 修改活动名称、标题颜色、背景颜色、标题字号
2. **导入名单** – 上传 `.txt`（每行一个姓名）或 `.xlsx`（第一列为姓名）
3. **奖项管理** – 添加奖项（名称、奖品、名额）
4. **内定人员** –（可选）为奖项指定内定中奖者
5. **上传照片** –（可选）为候选人上传头像

### 4. 开始抽奖
返回前台，选择奖项，点击「抽 奖」，姓名滚动后自动揭晓中奖者。


## 🔧 常见问题

**Q: 默认账号密码是什么？**  
A: 用户名 `admin`，密码 `ynos1234`。

**Q: 如何修改管理员账号密码？**  
A: 当前版本暂不支持在界面修改，如有需要可联系开发者定制。

**Q: 支持哪些名单文件格式？**  
A: 支持 `.txt`（每行一个姓名）和 `.xlsx`（取第一列作为姓名）。

**Q: 导入名单时提示失败？**  
A: 请检查文件格式是否正确，确保 `.xlsx` 文件第一列为姓名，且未加密。

**Q: 抽奖时姓名滚动不停止？**  
A: 请检查浏览器是否为最新版本，尝试刷新页面后重试。

**Q: 内定人员怎么设置？**  
A: 后台「奖项管理」→ 每个奖项右侧「内定人员」下拉框 → 选择人员即可。

**Q: 如何清空中奖记录？**  
A: 后台「中奖记录」卡片 → 点击「清空所有中奖记录」。

**Q: 页面顶部怎么添加图片或轮播图？**  
A: 后台「页面定制」→ 在文本框中编写 HTML 代码（可参考下方示例）。

**Q: 应用数据保存在哪里？**  
A: 名单、中奖记录、配置等数据保存在应用专用存储区，卸载应用时可选择是否保留数据。

**Q: 支持 ARM 架构的飞牛吗？**  
A: 支持，当前版本兼容 x86 和 ARM 平台。
